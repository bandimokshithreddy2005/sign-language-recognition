# 🤟 AI-Based Sign Language Recognition System

## 📌 Overview
The AI-Based Sign Language Recognition System is a web application that recognizes sign language gestures in real time using computer vision and machine learning. It helps bridge the communication gap between hearing-impaired individuals and others by converting sign language into understandable text.

## ✨ Features
- Real-time sign language detection
- Hand landmark detection using MediaPipe
- Machine Learning-based gesture recognition
- User-friendly web interface
- Fast and accurate predictions
- Easy to extend with new gestures

## 🛠️ Technologies Used
- Python
- Flask
- OpenCV
- MediaPipe
- Scikit-learn
- HTML
- CSS
- JavaScript

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Sarreddy-Meenakshi/sign_language_project.git
```

Go to the project folder:

```bash
cd sign_language_project
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
